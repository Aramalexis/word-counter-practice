# word-counter-practice

A tiny utility that counts word frequency in a text, used as a practice
repository for learning the GitHub pull request workflow.

## Usage

```python
from word_count import count_words

count_words("the cat sat on the mat")
# {'the': 2, 'cat': 1, 'sat': 1, 'on': 1, 'mat': 1}
```

## Running tests

```bash
python -m unittest discover
```
